# Showcase figure provenance

All PNG files in this directory are generated by
[`../generate_showcase_figures.py`](../generate_showcase_figures.py).

Data sources:

- `../PHASE2_FINAL_RESULTS.csv`
- `../PHASE2_PARETO_SUMMARY.csv`

Filtering rules:

- Method comparison charts use only `formal_validity_status=passed`, `seed=0`, and `recovery_status=none`.
- VisDrone formal bars therefore use clean runs with `actual_batch=4`; recovered `_b8` runs are excluded.
- `implementation_failed`, `not_executed`, OOM failures, and duplicate references are excluded.
- The stability chart is explicitly diagnostic and does not treat diagnostic rows as formal accuracy results.
- The audited `PHASE2_PARETO_SUMMARY.csv` designation is the four-objective front over accuracy, parameters,
  memory, and training time.
- The displayed accuracy-parameter chart does not reuse that designation. After formal-validity filtering, it
  independently recomputes a two-dimensional front that maximizes mAP50-95 and minimizes trainable parameters.
